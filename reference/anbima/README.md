# Referência pública ANBIMA

Snapshots pontuais usados para auditoria e validação externa dos modelos próprios
do Tesouro Radar. Estes arquivos não são a fonte principal do aplicativo e não
representam uma réplica da base histórica ANBIMA.

## Fonte

- Autor/fonte: ANBIMA - Associação Brasileira das Entidades dos Mercados
  Financeiro e de Capitais.
- Página: https://www.anbima.com.br/informacoes/est-termo/CZ.asp
- Endpoint público consultado:
  https://www.anbima.com.br/informacoes/est-termo/CZ-down.asp
- Formato da consulta: `Idioma=PT`, `Dt_Ref=DD/MM/AAAA`, `saida=xml`.

## Uso

O conteúdo é preservado sem alteração e acompanhado por SHA-256 no manifesto.
Crédito à ANBIMA deve ser mantido em qualquer divulgação. Os dados são apenas
informativos; a ANBIMA não se responsabiliza pelas análises, transformações ou
decisões realizadas por este projeto.

Não há coleta histórica automatizada configurada neste repositório.
